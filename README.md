# Sadang

## 잠실역 미니어처 (`jamsil-diorama/`)

잠실역 사거리를 중심으로 롯데월드타워, 롯데월드(어드벤처·매직아일랜드), 석촌호수,
잠실주공5단지, 갤러리아팰리스 등을 손으로 배치한 토이 스타일 3D 디오라마입니다.

- `jamsil-diorama/index.html` 한 파일로 동작합니다 (three.js 0.170.0을 jsDelivr에서 불러옴).
- 브라우저에서 바로 열면 됩니다. 로컬 파일로 열 때 모듈 로딩이 막히면 간단한 정적 서버를 쓰세요:
  `npx serve jamsil-diorama` 또는 `python3 -m http.server -d jamsil-diorama`.

### 기능
- 낮/밤 전환 (창문·가로등·타워 조명), 첫 화면은 서울 현재 시각 기준
- 계절 전환: 봄 석촌호수 벚꽃, 가을 은행나무 가로수, 겨울 눈 덮인 지붕
- 신호에 맞춰 움직이는 차량·버스·주황 택시, 매직아일랜드 자이로드롭과 롤러코스터, 호수 오리
- 틸트시프트(미니어처 사진 느낌) 효과, 이름표, 자동 회전

### 한계
OpenStreetMap 등 실제 지도 데이터 없이 대략적인 위치로 배치했습니다.
높이는 60m 이상부터 압축해서 표현합니다 (롯데월드타워 실제 555m).
실제 건물 데이터를 확보하면 같은 좌표계(1 unit = 10m, 원점 = 잠실역 사거리)로 교체할 수 있습니다.
